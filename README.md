# StibMap & Thread project

## StibMap 🚇
STIB Metro Shortest Path Finder is a Java application that calculates the shortest route for the Brussels metro using the official STIB API. By leveraging Dijkstra's algorithm, this application helps users determine the quickest path between metro stations in the STIB network.

### Features
 - Shortest Path Calculation: Utilizes Dijkstra's algorithm to find the shortest route between metro stations.
 - STIB API Integration: Fetches real-time metro data from the official STIB API.
 - Metro Network Visualization: Displays the metro network to users, showing the best route visually.
 - User-Friendly Interface: A simple and intuitive interface for selecting start and destination stations.
